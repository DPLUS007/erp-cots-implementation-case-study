# High-Level Milestone Plan

| Phase | Weeks | Key Outputs | Exit / Decision |
|---|---:|---|---|
| Mobilization | 1–3 | Charter, governance, stakeholder map, plan | Charter approved |
| Discovery | 4–8 | Processes, requirements, data/integration inventory | Requirements baseline |
| Design / Fit-Gap | 9–14 | Fit-gap decisions, solution design, role concepts | Design approval |
| Configure / Build | 15–22 | Configuration, integrations, migration iterations | Build readiness |
| System / Integration Test | 23–26 | Tested processes and interfaces | SIT exit |
| UAT / Readiness | 27–31 | UAT, training, cutover rehearsal, support prep | UAT/readiness sign-off |
| Cutover / Go-Live | 32–34 | Migration, production transition, go/no-go | Production live |
| Hypercare / Handover | 35–36 | Stabilization, support transfer, closure | Handover approved |

## Critical dependencies
- Business SMEs available during discovery/design/UAT
- Vendor decisions delivered to agreed dates
- Integration endpoints and test environments available
- Data owners complete cleansing/reconciliation
- Security/access decisions completed before UAT
- Training and operational support ready before go-live
